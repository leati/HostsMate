# HostsMate

绿色单文件的 Windows hosts 管理器。Rust + Win32 原生实现，无任何运行库依赖，
单 exe（约 650KB）双击即用。支持 Windows 10 1607+ / Windows 11。

![定位](https://img.shields.io/badge/定位-自用效率工具-blue)

## 功能

- **单表平铺管理**：所有记录一张表，双击单元格行内编辑（域名 / IP / 备注，
  IP 支持 IPv4/IPv6 并校验）、「启用」列点击翻转、新建/删除、Ctrl+N / Ctrl+S / Del 快捷键。
  兼容读取带 `#Group:` 分组的旧文件（原样保留其结构），但界面不分组、新文件不写分组标记
- **导入/导出**：`.host` / `.hosts` / `.txt`，导入按文件顺序追加到末尾
- **搜索**：Ctrl+F 聚焦工具栏右侧搜索框，按域名/IP/备注实时过滤
- **分类与状态筛选**：界面按域名和备注推断分类，可配合启用状态筛选；分类只影响显示，
  不会改写 hosts 文件内容。分类完全自定义：在「设置 → 分类规则」里添加 / 删除 / 重命名分类，
  每类一串关键词（逗号/顿号分隔），上移 / 下移调整匹配优先级（自上而下先命中先归类，
  全不命中归兜底「自定义」）。默认对域名和备注做包含匹配，`xx*` 形式按域名前缀匹配
  （如 `ad.*` 只命中 `ad.` 开头的域名，不误伤 `download.com`）。
  主界面筛选 chips 随分类增删实时重建。规则保存在 settings.ini，随程序设置一起持久化；
  旧版 ini（cat_cdn 等四键）首次读取时自动迁移为默认四类
- **备份管理**：设置窗内备份列表支持多选，「删除所选」批量清理（带确认），
  「恢复所选」单份回滚（选中多于一份会被拦截提示），也可打开备份文件夹直接操作
- **冲突自动检测**：实时检测同域名多条记录，红 = 真冲突（同域名不同 IP，会互相覆盖）、
  黄 = 冗余重复（同域名同 IP）；底部冲突条点击跳转；被覆盖行右键「置顶生效」；
  冗余重复一键清理；生效规则 = 文件顺序靠前者生效
- **非破坏性保存**：注释、空行、无法识别的行原样保留；UTF-8 读写（GBK 自动兜底解码）；
  原子替换写盘；保存前自动快照备份（默认留 20 份，设置可调），设置窗内可一键恢复
- **安全写盘**：普通权限运行，保存系统 hosts 时弹一次 UAC 由提权 helper 静默写盘
  （不再重启程序）；「以管理员身份重启」可常驻提权；保存成功后自动 `ipconfig /flushdns`
- **外部修改检测**：切回窗口时检测 hosts 被记事本等外部工具修改，自动重载或提示合并策略
- **右键工具**：ping（域名 / -t / -6 / IP）、浏览器打开、复制记录

## 使用

```
hostsmate.exe                 # 管理系统 hosts（C:\Windows\System32\drivers\etc\hosts）
hostsmate.exe --file 某文件   # 管理任意 hosts 格式文件
```

- **数据目录**：默认 `%APPDATA%\HostsMate\`（备份与设置）；
  exe 同目录放置 `HostsMate.data\` 文件夹即切换**便携模式**（数据存 exe 旁）
- 保存系统 hosts 需要管理员权限：程序默认普通权限启动，保存时弹 UAC；被安全策略
  拦截时可改用「设置 → 以管理员身份重启」

## 构建

```
cargo build --release
# 产物：target\release\hostsmate.exe（图标与 comctl32 v6 / PerMonitorV2 manifest 已内嵌）
```

## 设计说明

- 数据模型为**单文件就地标注**：系统 hosts 文件本身是唯一数据源，方案 = 文件内
  `#Group:` 块，方案开关 = 批量启停组内记录（`#Off` 前缀）。兼容读取旧版 hosts
  工具生成的同格式文件，标记双向无损往返

## 已知限制

- 高分屏为 PerMonitorV2 声明 + 基础缩放，多显示器跨屏拖动的字体清晰度未做逐屏调优
- 「同域名多条时文件靠前者生效」与主流 hosts 解析行为一致，但未在全部 Windows
  版本实测；如发现相反行为，引擎中为单行可切换实现
- hosts 仅精确匹配域名，不同子域名不视为冲突
